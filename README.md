### 🧩 Personal Knowledge-Graph Recall Agent

An intelligent **"Second Brain"** system that transforms passive document storage into a proactive knowledge graph. Using LLMs and ChromaDB, it silently monitors notes, autonomously extracts key entities, builds a semantic relationship graph, and proactively surfaces forgotten, contextually relevant notes with AI-generated reasoning — eliminating the need for manual searches.
